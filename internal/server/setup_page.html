🛠️ WorkBuddy2API 安装向导

首次启动需完成初始化：设置看板登录凭据，并生成网关访问密钥。

① 看板登录凭据

用于登录管理看板（浏览器会弹原生登录框）。至少 6 位。

② 网关访问密钥（api_key）

客户端（Codex / Claude Code / SDK）调用 /v1/* 时使用： Authorization: Bearer <key> 或 x-api-key: <key>。 留空自动生成 48 位随机串。
安装完成后本向导会**自动关闭**，/ 变为需要登录的看板。 凭据将写入 config.json。

✅ 安装完成

请立即保存以下凭据——密码与密钥只在此处完整显示一次。 之后可在 config.json 中查看或修改。
